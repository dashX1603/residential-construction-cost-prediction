# Residential Construction Cost Prediction

## Project Overview

Constructora Horizonte S.A., a fictional residential construction company in Costa Rica, seeks to improve its initial construction cost estimation process.

Traditionally, project budgets are estimated manually by analyzing characteristics such as:

- Built area
- Number of bedrooms
- Number of bathrooms
- Number of floors
- Finishing quality
- Terrain conditions

To support planning and decision-making, the company wants to evaluate whether Machine Learning techniques can generate reliable preliminary cost estimates for new residential projects.

The dataset contains information from 600 synthetic residential construction projects, including their physical and technical characteristics and the estimated construction cost in Costa Rican colones (CRC).
